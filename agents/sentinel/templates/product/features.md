# Features

Inventory of what the product does today, from the user's side. Owned by the analyst; updated when the user reports a feature delivered, and corrected on the spot when the user says the product behaves differently from what is written here. New features are described against this file — it is the analyst's picture of the current product.

One section per feature. Present tense: what the product does, not what was planned.
